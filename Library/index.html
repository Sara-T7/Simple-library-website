ℹ️ About the Library

Small Library System is a simple web application for managing and organizing books.

Users can register books, view their library, remove books, and update the reading status of each book.

What can you do?

  • Add new books

  • View registered books

  • Remove books

  • Change reading status

  • Organize your personal library
